[今日股票] 净利润260亿日元背后的反转:股息率超5%的日本耐火材料龙头品川耐火材料(5351)

psythinktank_RA|2026.11.11
조회수 00 views閲覧数 0浏览量 0

数字亮眼,今年利润却在缩水?品川耐火材料的两面

品川耐火材料(品川リフラクトリーズ,东京证券交易所Prime市场,5351)生产铺设在钢铁厂高炉、电炉内壁的耐火材料(在高温下不熔化、不坍塌的砖块、水泥类材料)。在炼钢工序中,它像消耗品一样需要不断更换,因此公司命运与钢铁行业景气紧密相连。现在值得关注这家公司的原因,在于一组相互矛盾的数字:“去年净利润大幅飙升,今年反而预计下降”。

1. 近期股价与基本信息

  • 近期股价:约1,847日元(基于截至2026年11月6日的提供数据。11月11日当天的收盘价未能确认)
  • 10月初股价在1,945~1,976日元区间,此后有所回落。
  • 市值:10月初约为929亿日元,按当前股价估算约为870亿日元左右(估算值)。
  • 1年股价涨跌幅为-0.22%,一年来基本原地踏步。

2. 2026年3月财年:营收与利润均表现良好

项目2026年3月财年
营业收入约1,777亿日元(同比+23.4%)
经常利润约159亿日元(+17.1%)
净利润约260亿日元(+166.6%)
每股收益(EPS)571.45日元
全年股息90日元

引人注目的是,净利润(260亿日元)远大于经常利润(159亿日元)。主业之外的一次性收益有可能推高了净利润(具体明细本文未能确认,属于推测)。因此,很难把净利润增幅超过100%的数字直接解读为“真实实力”。

3. 2027年3月财年:营收增长但利润回落

公司在2026年8月发布第一季度财报的同时,上调了今年的业绩预期。

  • 营收预期:1,890亿 → 1,980亿日元(上调约4.8%)
  • 经常利润预期:130亿 → 140亿日元(上调约7.7%,但仍低于去年的159亿日元)
  • 净利润预期:约105亿日元(较去年的260亿日元大幅下降)
  • 上半年(4~9月)预期:营收950亿日元,营业利润45亿日元,净利润65亿日元

据报道,第一季度(4~6月)营业利润约为17亿日元,同比下降约40%。原因据称是负责高炉设计与安装的工程部门亏损扩大,以及原材料和燃料成本上涨。也就是说,“销量增加但留下的钱变少”的结构,是今年的核心课题。

4. 股息:按当前股价超过5%

今年的预计股息为95日元(中期47日元、期末48日元),比去年增加5日元。按1,847日元计算,股息率约为5.1%。预计派息率(利润中用于分红的比例)在40%出头,显示出即使在利润下滑的年份也愿意提高股息。不过,股息只是随时可能变动的预定值。

5. 大股东结构:JFE钢铁持股33.74%

股东持股比例(2026-10-01)
JFE Steel33.74%
Kobe Steel3.74%
Fukoku Mutual Life Insurance2.12%
Sumitomo Mitsui Trust Bank2.08%
Mizuho Bank1.81%

第一大股东JFE钢铁持股超过三分之一,意味着拥有稳定的客户和股东基础,但业绩可能在很大程度上受单一钢铁企业设备投资和生产计划的左右,这是一个风险因素。韩国国民年金并未持有该股票。其日成交额中位数全年约为1.7亿日元,成交量不大,交易时需留意价格波动。

6. 后续关注要点

  • 中期财报发布:据称预定在11月中旬前后,实际数据尚未确认。关键在于是否达成上半年预期(营业利润45亿日元)。
  • 工程部门盈利能力能否恢复
  • 原材料、燃料价格以及向产品价格转嫁成本的能力
  • 日本钢铁产量走势
  • 房地产、休闲部门(高尔夫球场、酒店等)带来的稳定现金流

总之,对于品川耐火材料,与其看去年亮眼的净利润,不如同时关注“主业利润能恢复到什么程度”以及“5%以上的股息能否维持”。
