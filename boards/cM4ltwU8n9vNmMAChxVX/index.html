1. 로그인 실패 5회 이상 시 계정 잠금

비밀번호 불일치 횟수가 5번 이상인 경우 로그인이 불가합니다. 따라서, 비밀번호를 여러 번 틀렸을 경우 비밀번호 찾기 기능을 통해 임시 비밀번호를 발급받은 후 로그인 해주시기 바랍니다.


2. 회보 게시판 변경

회보 메뉴를 게시판 형태로 변경하여 지금까지 발행된 회보를 모두 열람할 수 있도록 하였습니다.


3. 기타 변경 사항

게시판 검색 기능 추가
